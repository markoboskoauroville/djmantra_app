## Manual checks

| check | result | notes |
|---|---|---|
| APK installs | **fail** as shipped, pass after local signing | The CI artifact `mixxx.apk` (and `android-build-release-unsigned.apk`) is **unsigned**: `adb install` → `INSTALL_PARSE_FAILED_NO_CERTIFICATES: Failed to collect certificates … Attempt to get length of null array`. A copy zipaligned and signed locally with the standard Android debug key installs fine (`com.djmantra.app`). CI should sign the APK (debug key is enough for testing). |
| App starts and is still running after 20 s | **fail** | Crashes immediately on launch (08:04:59, 0.3 s): `FATAL EXCEPTION: qtMainLoopThread` → `java.lang.UnsatisfiedLinkError: dlopen failed: library "libomp.so" not found: needed by …/lib/arm64/libmixxx_arm64-v8a.so` (from `QtLoader.loadLibraryHelper`). The APK's `lib/arm64-v8a/` has `libc++_shared.so` but **no `libomp.so`**: OpenMP is linked dynamically but not packaged. Fix: link OpenMP statically (`-static-openmp`) or add the NDK's `libomp.so` to the APK's extra libs. |
| What is on screen? | fail | No app window and no error dialog: Android returns straight to the home screen (screenshot). |
| Android lists audio outputs in `audio_policy.txt` | pass | Emulator: Speaker attached; Bluetooth A2DP / hearing aid / remote submix / telephony declared. No USB DAC or real Bluetooth on an emulator. |
